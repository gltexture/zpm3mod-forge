ZombiePlague3

ZombiePlague3 is a Minecraft Forge mod for Minecraft 1.20.1.

GitHub

The mod is currently under active development, and its architecture and APIs may change over time.

📌 Overview

This documentation provides a concise guide to the ZombiePlague3 0.2 Alpha API for developers who want to create addons and extend the mod.

The documentation focuses on practical addon development rather than the internal implementation of ZombiePlague3.

It covers addon initialization, registration systems, events, networking, client/server separation, and other APIs exposed by the mod.
